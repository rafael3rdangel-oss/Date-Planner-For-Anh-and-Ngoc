How to use the storybook

  1. Create or select a book, like Vietnam 2025, Next Vietnam, Belgium memories, or Anniversary.
  2. Upload a PDF if you have a full document for that book.
  3. Upload cute images or page previews. Around 7–12 images is enough for a nice storybook.
  4. Create periods/chapters, like Before trip, Day 1, Da Lat, Last day, or Belgium winter.
  5. Add custom story pages into a period if you want date captions, quotes, tags, and little story text.
  6. Edit or delete pages directly from each story page using the buttons under the tags.
  7. Use the relationship timeline to send a saved plan or memory into the selected storybook.
  8. Use Storybook photo shelf to quickly open uploaded images larger.
  9. The full PDF stays in Supabase, while the app shows a soft readable storybook version.

🌷 How to use this app

1. Save ideas: add food, places, games and activities in Library.

3. After the date: use the review shortcut to save the memory into Journal.
4. Keep it safe: download a backup sometimes from Tech.
✨ Mini stickers

Shortcut stickers

You can insert normal, moving, and silly stickers with the picker, or type sticker shortcuts manually inside supported titles and note boxes.

Easy way: tap a title or note field, then tap a mini sticker from the floating sticker picker.
Shortcut way: type a shortcut like [sticker:cat] or [sticker:heart] directly in the text.
Moving stickers: type shortcuts like [sticker:cat-bounce], [sticker:heart-pulse], or [sticker:star-spin]. These animate after saving, like tiny Discord/Steam-style stickers.
Silly pack: try cute shortcuts like [sticker:bunny], [sticker:frog], [sticker:pudding], [sticker:toast], [sticker:ghost-float], or [sticker:bunny-hop].
Where it works: plan titles/notes, period plans, library names/notes, journal titles/bodies, couple profile fields, and edit popups.
Important: save the form after adding a sticker, then it will show as a cute small sticker in the app. Animation may not show inside the text box itself.

🔎 app review

What can still be improved?

The app is already useful, but these are the best next upgrades I would consider.

1. Storybook page order: add move up / move down buttons so pages can be rearranged inside a period.
2. Better image management: add replace image, remove image, and choose image from uploaded shelf without typing image numbers.
3. PDF page importer: upload one PDF and let the app make page previews automatically. This would need server-side work, not just index.html.
4. Plan calendar view: a cute monthly calendar would make wrong dates easier to notice.
5. Plan date merging: if two plans exist on the same date, add a safe merge option instead of blocking the move.
6. Image compression: compress photos before uploading to Supabase so storage lasts longer.
7. Storybook export: export a memory book as PDF/HTML for printing or saving offline.
8. Private file check: add a small Tech status checker for Supabase bucket/policies so private uploads are easier to verify.
Best next update from this list: storybook page order + better image picker. That would make memory books much easier to clean up.
